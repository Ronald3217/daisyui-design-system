# daisyUI Design System Skill

**Important:** When you see class patterns like `$$componente`, replace them with actual daisyUI classes.

**Pattern:** `$$componente $$componente-$$variant` → `componente variant`
- `$$input $$input-$$variant` → `input input-primary`
- `$$button $$button-$$variant` → `btn btn-primary`
- `$$badge $$badge-$$variant` → `badge badge-primary`
- `$$alert $$alert-$$variant` → `alert alert-info`

**Available variants by component type:** `primary`, `secondary`, `accent`, `neutral`, `info`, `success`, `warning`, `error`

**Style modifiers:** `outline`, `dash`, `soft`, `ghost`, `link`
