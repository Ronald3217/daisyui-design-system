# Theme & Color Overview

> daisyUI theming system and color utilities.

---

## Default Theme Colors

| Color Name | CSS Variable | Usage |
|------------|-------------|-------|
| **primary** | `--color-primary` | Main brand color |
| **secondary** | `--color-secondary` | Secondary brand |
| **accent** | `--color-accent` | Accent color |
| **neutral** | `--color-neutral` | Dark neutral |
| **base-100** | `--color-base-100` | Page background |
| **base-200** | `--color-base-200` | Elevated surface |
| **info** | `--color-info` | Info messages |
| **success** | `--color-success` | Success messages |
| **warning** | `--color-warning` | Warning messages |
| **error** | `--color-error` | Error messages |

---

## Color Utility Classes

```html
<!-- Background -->
<div class="bg-primary"></div>
<div class="bg-success"></div>

<!-- Text -->
<p class="text-primary"></p>

<!-- Border -->
<div class="border border-primary"></div>
```
